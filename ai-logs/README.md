# AI logs

This folder holds the full history of the AI conversations used to build this project, wrong turns included (take-home brief, §2).

## What is here

| File | Session |
| --- | --- |
| `00-planning/kitchen-queue.prompt.json` | The build plan produced in the planning session. |
| `00-planning/PLAN.md` | The readable version of that plan, with the amendments the author requested before the build. |
| `01-planning-session-build-plan.md` | Planning session: from the take-home brief to the JSON plan. |
| `02-planning-session-plan-review.md` | Plan review: PLAN.md, two rounds of author amendments, the first commits. |
| `03-build-and-review-session.md` | Build of tasks T01 to T15, then a full review of the repository and its fixes. Same session as 02. |

The author's planning prompt is in `docs/prompt1.md`.

## How to read the session logs

- Prompts and replies are verbatim and in order.
- Tool calls are collapsed. Long commands, outputs and file contents are abbreviated.
- Logs 02 and 03 were generated by a script from the session transcript that the tool stores on disk; each file says so in its header.
- Log 03 replaces a few names that belong to other work on the author's machine (containers of another project, a second account). Its header gives the count.

The AI section of `DECISIONS.md` is written by the author, not by the assistant.
